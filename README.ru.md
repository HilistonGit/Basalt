# Basalt
### Современный VPN — с вниманием к старой Windows

**Два современных ядра · .NET Framework 4.0 · старые Windows · x64 и x86**

Basalt — современный десктопный VPN-клиент на базе **Xray и sing-box**, созданный с прицелом на обратную совместимость. Его задача — дать пользователям старых Windows доступ к актуальным протоколам, полноценному туннелю и удобному управлению подключениями.

## 🪨 Современный VPN для систем, которые ещё нужны

Basalt разрабатывается прежде всего для **Windows 8 и 8.1**: хочется пользоваться современными VPN-протоколами, не меняя операционную систему только ради клиента. Один интерфейс объединяет два ядра — **Xray и sing-box** — и выбирает подходящее для профиля. Можно направить через VPN весь компьютер или разделить трафик правилами маршрутизации.

Обратная совместимость заложена в двух частях приложения:

- **Лёгкая оболочка на .NET Framework 4.0 / Windows Forms.** Без Electron, WebView и встроенного браузера. Выбор этой платформы позволяет рассматривать даже Windows XP как цель для оболочки, хотя запуск самой Basalt на XP пока не подтверждён испытаниями.
- **Современные ядра в специальных legacy-сборках.** В пакет входят Xray 26.10.21 и sing-box 1.14.4, подготовленные upstream для Windows 7 и новее. **Legacy здесь означает целевую операционную систему:** современные версии ядер собраны для старых Windows. Basalt использует официальные legacy-релизы и проверяет их контрольные суммы.

> **Оболочка и VPN-ядра имеют разные требования.** .NET 4.0 не делает весь комплект совместимым с XP: поставляемые ядра и TUN на XP не работают. Основной приоритет — Windows 8/8.1; отдельные испытания на этих ОС ещё предстоят.

## ⚡ Возможности

- **Xray и sing-box** с автоматическим выбором ядра: VLESS, Trojan, Shadowsocks, Hysteria2; TCP, WS, gRPC и XHTTP в зависимости от протокола.
- **TUN для всего компьютера**, системный прокси или прокси для приложений.
- **Маршруты подписки** Happ, Xray / sing-box JSON и поддерживаемые правила Clash YAML. Полный конфиг не заменяется сокращённым Happ-заголовком.
- GeoSite / GeoIP, загрузка и проверка удалённых наборов правил.
- Автообновление подписок, общие User-Agent и HWID, сохранение серверов в зашифрованном профиле Windows.
- Тёмный интерфейс, трей, **русский и английский** с переключением без перезапуска. По умолчанию — язык системы: русский для русской Windows, иначе английский.
- **Автозагрузка и автоподключение**: сохранённые серверы → обновление подписок → подключение. Ошибка или частичный ответ не уничтожает прежний список; неудачное автоподключение повторяется с увеличением интервала.

## ✨ Подписки — основа интерфейса

Скопируйте ссылку провайдера и нажмите **Ctrl+V**. Серверы собраны по подпискам; рядом — трафик, срок действия, обновление и HTTPS-проверка. Есть поиск, избранное, сортировка по задержке, обозначения стран и редактирование JSON outbound с проверкой ядром.

## 🚀 Начало работы

1. Скачайте полный ZIP из [Releases](https://github.com/HilistonGit/Basalt/releases/latest) и распакуйте его. Универсальный пакет содержит оба варианта ядер; `-x86` — только 32-битные.
2. Запустите `Basalt.exe`, сохранив рядом каталог `cores`.
3. Вставьте HTTPS-ссылку подписки. User-Agent и HWID задаются в **Настройки → Подписки**.
4. Выберите сервер и подключитесь. Для TUN нужны права администратора.
5. Проверьте соединение. Крестик скрывает окно в трей; завершение — через пункт «Выход».

**Настройки → Интерфейс:** язык, запуск с Windows и подключение при запуске. Два последних параметра по умолчанию выключены. Автозагрузка использует задачу Windows для текущего пользователя с наивысшими доступными правами; включение запрашивает UAC. После переноса portable-папки перевключите автозагрузку, чтобы обновить путь.

## 🔄 Обновления

**Настройки → Обновления → Проверить обновления.** Клиент проверяет GitHub Releases этого репозитория, выбирает нужный архив и проверяет размер и SHA-256 после загрузки. Установка ручная: завершить приложение через трей, распаковать архив, запустить новую версию. Подписки остаются в `%LOCALAPPDATA%\Basalt`.

## 🧭 Совместимость и ограничения

Главная цель — **Windows 8 / 8.1**, но отдельные испытания в VM ещё необходимы. Проверки на современной Windows их не заменяют. Поставляемые ядра и TUN **не поддерживают Windows XP**.

Оболочка — .NET Framework 4 Full / Windows Forms, без Electron и WebView. Для других ОС интерфейс пока не реализован. Поддержка Clash не полная: MRS, classical providers, fallback и ряд расширений отклоняются явно. Подробнее: [совместимость](docs/compatibility.md).

## 🛠 Разработка

```powershell
./scripts/fetch-framework-references.ps1
./scripts/build.ps1
./scripts/fetch-official-cores.ps1
./scripts/package.ps1
```

Сборка запускает проверки модели и UI. Интеграционные и сетевые тесты описаны в [инструкции релиза](docs/RELEASING.md).
